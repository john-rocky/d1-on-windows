Speed of the four GenAI CPU rows measured again with High QoS, 2026-11-11, Windows 11 build 26200.9711, on the same
laptop as the published numbers (drivers: Intel(R) Graphics 32.0.101.8724, NVIDIA GeForce RTX 5080 Laptop GPU 591.74).
This file lists each timed process of the rows that count.

The models, Python environments and request file of the published runs, unchanged.

How: every timed run is a new Python process started over ssh (Win32_Process.Create); the sitting lines below give
the desktop's state (LogonUI = Windows' lock-screen process) and the laptop's power mode (MSI Center's User Scenario,
registry Mode 2 = Balanced, and Windows' power mode overlay, none = Windows' Balanced mode) at the start and the end
of each sitting.
It runs the published script unchanged (runpy), with the published number's arguments.
High QoS = the process calls SetProcessInformation(ProcessPowerThrottling, ControlMask = EXECUTION_SPEED,
StateMask = 0) at its start, before the published script and its imports run (the wrapper imports only ctypes,
json, os, sys and time before the call); default = no call. Each process reads the state back
(ControlMask/StateMask) at its start and at its end, and times a fixed 30,000-iteration Python loop at its start
and three times at its end (the end value below is the fastest of the three, with the core type it ran on).
State 1/0 = power throttling opted out (High QoS); 0/0 = nothing set.
At their end, the loop took 0.76 to 0.88 ms in the High processes below and 2.30 to 2.35 ms in the default ones.
Order per row: High, default, default, High. A row's value = the mean of its two processes of one QoS.
Controls: a static fp16 graph on the Intel GPU (Windows ML, OpenVINO EP, 101 tokens, default QoS), known 98.2 ms,
before and after each row, and in the middle of the rows that take over 10 minutes; a row counts when all its
controls are within 5 % of the known value.
